# Before contributing

This project was initially a learning project for **building a game on Steam utilizing all Steam features**. Open-sourcing means everyone can just modify the game to their needs and learn some things. 

I don't expect to get contributors on this project, since I'm also focusing on other stuff, so expect slow review and merge if you want to contribute, but if you're willing to be a contributor or maybe a maintainer, I'd be glad to have you. 

If you just want to fork to a community-driven version, **you can do that as well**.

# Who can contribute

Everyone can contribute to this project, just make sure you own the changes you make.

# What to contribute

Bug reports are welcomed, feature request will likely be ignored unless someone wants to work on it. Use [Issues](https://github.com/Squalive/banana-shooter/issues) for these.

## Pull Requests

You submit changes via pull requests, [click this to learn how it works](https://docs.github.com/en/pull-requests/reference/pull-requests).

### Code Only changes 
These are the preferred contributions, it is easy to get reviewed and can be unit tested easily.

### Asset changes
These are not `BS` focus right now, expect to get rejected or left pending after submission.
