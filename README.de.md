# Banana Shooter
[Banana Shooter](https://store.steampowered.com/app/1949740/Banana_Shooter/) ist ein schnelles Ego Shooter Spiel bei dem man sich bewegt und auf die Bösen schießt.

![hero](docs/images/hero.jpg)

Dieses Repo ist für die, die neugierig auf einen blick **Hinter den Kulissen** sind, und auch für Leute, die abgeleitete Werke machen wollen.

Nebenbemerkung: Dieses Projekt hält beim Einsatz von Unity nicht die besten Standards ein, bitte folge nicht dem, was ich hier gemacht habe!

# Starte das Spiel
