# Banana Shooter
[Banana Shooter](https://store.steampowered.com/app/1949740/Banana_Shooter/) is a fast paced first person shooter game where you move and shoot the bad guys.

![hero](docs/images/hero.jpg)

This repo is for those who are curious about the **Behind the scenes**, and is also for people to make derivative work if wanted.

Side node: this project does not hold a good standard at best practices when using Unity, please dont follow what I have done here!
